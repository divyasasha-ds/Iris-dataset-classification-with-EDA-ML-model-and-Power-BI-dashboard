🌸 Iris Dataset Classification with EDA, ML Model & Power BI Dashboard

A complete end-to-end Data Science project using the classic Iris flower dataset, covering Data Cleaning, Exploratory Data Analysis (EDA), Machine Learning Models, and an interactive Power BI dashboard for insights.

📌 Project Overview

This project aims to classify Iris flowers into the species:

Setosa

Versicolor

Virginica

Based on four key features:

Sepal Length

Sepal Width

Petal Length

Petal Width

This repository demonstrates the entire Data Science workflow — from raw data → cleaned data → EDA → ML model → BI visualization.
